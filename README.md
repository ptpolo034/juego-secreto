# Juego del número secreto

Ejercicio del curso de lógica de programación de **Alura Latam**. Es un juego en el navegador donde el programa
escoge un número del 1 al 10 y yo tengo que adivinarlo.

## Cómo se juega

1. Escribo un número y presiono **Intentar**.
2. El juego me dice si el número secreto es mayor o menor.
3. Cuando acierto, me muestra en cuántos intentos lo logré y se activa **Nuevo juego**.
4. No repite números ya sorteados dentro de la misma partida.

## Cómo lo uso

No necesita instalar nada: abro `index.html` en el navegador.

## Tecnologías

HTML, CSS y JavaScript puro.
